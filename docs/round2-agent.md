# 第二轮方向三：个人情感追踪与可执行支持 Agent

日期：2026-11-15。代码已实现，未提交或部署到外部服务。本报告中的测试用户和心情记录全部为自编隔离夹具，没有真人参与。

## 本轮结果

疗愈空间新增“我的持续陪伴”卡。用户明确开启后，系统只读取其本人最近 14 天、最多 14 条已经发生的心情自评，整理历史并根据活动偏好提供一个可接受或跳过的小活动。开启并进入页面后可以主动出现建议，**提议本身不播放音频、不启动练习**。

活动链路已贯通：

```text
显式开启 → 本人自评历史 → 规则式建议 → 接受/跳过
    → 点击启动 → 本地呼吸动画 / 原生 Audio 雨声
    → 启动回执 → 完成 / 失败 / 取消 → 本人反馈
```

这里的 Agent 是有状态、白名单工具驱动的规则式支持 Agent，不是已训练的自主决策模型。没有使用 RQI、MIS、CUSUM 分数决定是否干预，也没有更改危机检测、审计、安全阈值或升级流程。

## 已实现的能力和边界

| 能力 | 具体实现 |
|---|---|
| 本人历史与可解释追踪 | HTTP 认证+PATIENT 角色；用户 ID 仅取认证结果。读取 MoodRecord，自评以外的分类器概率不混入。少于 3 条不输出均值/首末变化；超过 48 小时未更新不推荐新活动。这里只描述过去，不预测未来。 |
| 明确加入与退出 | 默认关闭；关闭状态不读取心情历史。用户关闭立即中断本页工具，服务器取消未完成活动。已保存的历史不会因关闭而删除，可通过现有隐私删除流程处理。 |
| 规则式个性化 | 优先遵循本人呼吸/自然音偏好；无偏好时仅依据最近自评情绪提供一个可跳过的选项。理由同时呈现自评来源。没有最优策略或疗效承诺。 |
| 主动提议 | 本人在本页开启、近期有自评且没有活动/处于冷却期外时，自动生成一条建议；六小时内不反复提议。不存在后台跨天监控或系统通知。 |
| 真实工具执行 | 呼吸为两轮 4/4/6 秒的可中断动画；自然音使用与原疗愈空间相同的固定雨声音源，通过浏览器原生 Audio 执行。音源由固定 resourceId 映射，不接受任意 URL。 |
| 状态与回执 | offered→accepted→running→completed；另有 declined/cancelled/failed/expired。必须明确接受再点击启动。播放拒绝、网络播放错误、缓冲中断及启动超时进入失败处理，不记录为完成。 |
| 完成与反馈 | 完成要求启动令牌匹配、状态正确及服务器观测时长满足活动时长。本人可反馈有帮助/一般/没有帮助；反馈不改变活动结束时刻。执行回执来自浏览器报告，不是独立、不可伪造的行为或疗效证明。 |
| 故障和并发 | 每个命令带版本和 UUID 幂等键；载荷严格校验。数据库真实用户父行锁串行写入，接受动作与实际活动创建同一事务。成功响应丢失可重试相同请求；不能用同编号提交不同内容。 |
| 可撤回 | 本页停止立即释放计时器、音频；页面隐藏中断，刷新不自动重播。活动运行时每 2 秒读取状态，其他窗口关闭后正常网络下停止本页工具；断网时不保证跨窗口同步。 |

## 持久化与数据口径

没有数据库迁移。复用现有 HealingSession.metadata，以保留类型 `support_agent_state` 存放每用户一条设置、动作摘要和幂等日志；实际接受的活动另建 `breathing` 或 `music` 会话。

状态最多保留 20 个动作、64 个幂等请求摘要、64 KiB JSON；完整实际活动记录遵循已有数据保留机制。幂等保证适用于保留的请求窗口，不声称永久保存所有请求。

保留状态行从疗愈列表、疗愈统计及周报练习计数中排除。成长/成就读取 completed=true 的活动，状态行始终未完成。普通疗愈创建/完成接口拒绝保留类型及 Agent 管理活动，防止绕过 Agent 状态机修改元数据。已有数据导出、删除、账号级联与保留期清理仍覆盖该状态行，不会遗漏隐藏的个人记录。

## 尚未完成

1. **自主策略训练与独立对照：** 没有使用 ESConv/ToolACE 训练决策模型，没有证明当前规则优于固定活动、直接建议或原系统。下一步需冻结策略、盲评建议适配性，单独评价用户接受和帮助程度。
2. **与前两方向模型的联动：** 当前使用本人自评；未将新 VLM/MoE、未来预测、知识图谱推断用于实时工具决策，也未将第一轮理解卡的原话修正自动转为个体知识节点。
3. **纵向预测与后台追踪：** 当前是有界历史整理和进入页面时的主动提议，没有后台跨天调度、移动通知或长期恶化预测。真实长期预警数据仍缺。
4. **长期记忆和策略学习：** 当前只保留显式活动偏好和有界动作摘要，没有从“有帮助”反馈自动调整策略；没有强化学习或离线策略效果评估。
5. **扩展工具：** 尚无外部平台、跨工具互斥、第三方账号授权或系统级任务执行。自然音依赖现有 CDN；已实现失败处理，未提供离线媒体包。
6. **真实用户与专业评价：** 尚未验证青少年可接受性、建议时机、实际使用率或心理改善；合成测试夹具的成功不能替代真人研究。浏览器报告也不能证明用户按节奏呼吸或主观体验改善。
7. **真实全站部署：** 本轮使用隔离数据库和新路由完成端到端，未迁移用户原有数据库、未发布公网，亦未覆盖各浏览器/网络条件的大规模测试。
