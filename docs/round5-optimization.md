# 第五轮优化结果

完成于2026-11-16，完整记录见[第五轮报告](D:/Develop/AIC/_国赛优化/第五轮优化报告-20261116.md)。

在原821条历史留出样本上，最终可用性路由方案macro-F1为 **0.626614**，相对原拼接0.565738提升 **10.7606%**；accuracy为 **81.3642%**。中性召回仍只有9/85，不能称为可靠中性识别。

实际接入官方ECISA中文隐式情感辅助数据，14,620条含6,896条中性。新文字表征、人脸表情统计和轻量融合承担有媒体输入，ECISA适配模型承担媒体不足时回退。路由仅按703条开发样本选，缺必需文字时弃权。

第二份未参与选择的3,363条ECISA文字保留集上，回退模型macro-F1为0.7019；匹配同架构无辅助数据对照为0.5103。这是同一ECISA数据家族的文字验证，不是全新三模态或青少年临床验证。

模拟覆盖120个支持交互用户及100个Agent业务用户，真人参与者为0。模拟不替代真实主观帮助效果、问卷字典或真实纵向结局。

验证：**1,758 passed／1 skipped**，另有46项逐样本复算检查通过。所有失败、对照、选择锁定、源码快照和研究工件位于[round5](D:/Develop/AIC/_国赛优化/round5)。新模型清单标记uncalibrated，未替换默认业务模型。
