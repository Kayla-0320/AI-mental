## 八、关键发现

### P0 问题（已修复）

1. ~~**基线同步端点 500 错误**~~：`PersonalBaseline.from_dict()` 中 `v.get("mean")` 对纯数值调用 `.get()` 导致 AttributeError。**已修复**：增加类型判断，纯数值自动转为 `BaselineMetric(mean=value, std=0, n=1)`。

2. **个人画像 5 个 API 缺失**：`/api/profile/psychological`、`/api/profile/mood-trend` 等 5 个端点返回 404。
   - 影响：前端页面显示降级数据
   - 建议：实现缺失的 API 端点

### P1 问题（功能性）

1. **文本感知层降级为规则引擎**：所有情绪分析走规则引擎而非 ML 模型。
   - 影响：情绪识别精度低于预期
   - 建议：加载训练好的文本情感模型

2. **`/health` 端点 404**：健康检查端点未注册。
   - 影响：无法通过标准健康检查监控服务状态
   - 建议：注册 `/health` 端点

3. **`GET /intervention/audit-events` 500 错误**：审计事件查询端点服务端错误。
   - 影响：审计日志查询功能不可用
   - 建议：排查服务端错误
