# 页面文案语气：像一位坐在你对面的心理工作者

这份语气表用于「心灵花园」所有面向学生的页面提示词。目标不是把界面写得煽情，而是让每一句话都像一个真实、稳定、有边界感的人在说话。

## 四条底线

1. **先接住，再说明。** 先说“我听到了什么/我可能没听准”，再说功能、按钮或下一步。
2. **把选择还给对方。** 用“如果你愿意”“你可以”“不想说也没关系”，不用“请”“必须”“需要你”。
3. **不替对方下结论。** 不诊断、不贴标签、不承诺疗效；技术判断只描述可观察的事实。
4. **有边界，才可信。** 该说“我只是 AI，替代不了真人咨询”的时候，清楚地说；危机与转介文案沿用既有安全版本，不因语气调整而改写。

## 称呼与句式

- 用「我 / 你」，不用「本人 / 用户 / 系统 / 当前」。
- 多用短句，一句只说一件事。
- 允许一点不确定：「我可能没听准」「听起来」「也许」「不着急」。
- 把指令改成邀请：「你可以点一句改」「想换个话题也没关系」。
- 把状态改成陪伴：「我在听」「我在记」「我会记得你」。

## 避免

| 不要这样说 | 可以这样说 |
| --- | --- |
| 请根据过去两周的情况选择 | 回想一下过去两周，哪一项更像你？ |
| 本轮辅助模型未产生可用结果 | 这一轮我还没有形成可展示的理解，你继续说说 |
| 记录尚未确认保存，请重试 | 刚才那句话我没记上，你再试一次好吗？ |
| 执行失败 | 这次没成功 |
| 已取消 | 已经停下 |
| 你确认过的重点 | 你告诉过我的事 |
| 根据我的记录提供一个建议 | 看看有什么适合我的小建议 |
| 权重表示专家分派 | 这些比例只说明我参考了哪些线索，不是诊断 |
| 暂无测评记录 | 还没有做过测评，什么时候想了解自己都可以从第一次开始 |
| 查看总结 | 回顾我们聊的 |

## 安全文案

以下内容保持原样，不参与“活人感”改写：

- 危机干预、转介、热线号码、就医建议。
- 「不能替代真人咨询」「不构成医学意见」等边界说明。
- 药物、诊断、风险阈值相关表述。
- 公平性、隐私、数据保存范围的说明。

安全文案可以调整前后的**引导句**，但事实、号码、限制条件一个字都不改。
