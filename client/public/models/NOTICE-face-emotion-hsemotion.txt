模型事实（本仓库实测，不是抄文档）
--------------------------------
输入     `input`  [batch, 3, 224, 224]  float32，RGB
预处理   x/255 → ImageNet 归一化 mean=[0.485,0.456,0.406] std=[0.229,0.224,0.225]
         （不加归一化时本地域准确率 84.3% → 75.8%，已实测）
输出     `output` [batch, 8]，顺序：
         Anger, Contempt, Disgust, Fear, Happiness, Neutral, Sadness, Surprise
         （用 336 种映射穷举在带标签数据上验证，最佳排列与之一致）
官方指标 AffectNet-8 准确率 61.32%（原始 PyTorch 版本，官方 README 表格）

本仓库对它的用法
----------------
只取 Happiness→开心、Neutral→中性、Sadness→悲伤 三类做展示，
其余五类**不丢弃**：折叠不进去的概率由 `FaceEmotionReading.offMapProbability`
如实上报，界面显示「其他表情 X%」。折叠与归一化的实现见
`client/src/services/faceEmotionClassifier.ts` 的 `FACE_EMOTION_SPEC` / `toReading`。
全程在本机 canvas + WASM/WebGPU 内完成，不传帧、不落盘。

为什么换掉自训练的 ResNet50（3 类）
----------------------------------
在公开的真实世界成人人脸数据集 RAF-DB test 上（n=794）实测：

  旧模型（自训练 ResNet50，89.6 MB）
    真实笑脸 → 判成「悲伤」  56.9%（喂紧取景原图时 98.3%）
    真实中性脸 → 判成「悲伤」 92.5%
    sad 的 AUC               0.630
  新模型（HSEmotion，15.3 MB）
    真实笑脸 → 判成「悲伤」  0.8%
    真实中性脸 → 判成「悲伤」10.8%
    sad 的 AUC               0.965

代价：本仓库自带数据集上的三分类准确率由 97.2% 降到约 84%，但该数据集的 `sad`
大量是婴幼儿嚎哭（8 类模型读成 Fear/Surprise），并不衡量"成年人难过"。
完整证据链、复现命令与取舍见 docs/fer_external_model_integration.md。
