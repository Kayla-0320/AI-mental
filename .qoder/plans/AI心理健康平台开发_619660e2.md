# 多模态AI心理健康平台开发计划

## 技术架构

| 层级 | 技术选型 |
|------|---------|
| 前端 | React 18 + TypeScript + Ant Design + React Router + Zustand |
| 后端 | Node.js + Express + TypeScript + Prisma ORM |
| 数据库 | PostgreSQL + Redis (会话缓存/消息队列) |
| AI服务 | 百度文心一言 API (文本对话/情感分析/图像理解) |
| 实时通信 | Socket.IO (消息推送/在线咨询) |
| 文件存储 | 本地存储 (可迁移至 OSS) |
| 认证 | JWT + Refresh Token |

## 数据库核心模型 (Prisma Schema)

- **User**: 用户基础表 (患者/咨询师/管理员，通过 role 字段区分)
- **PatientProfile**: 患者扩展信息 (心理状态评估、基本信息)
- **ConsultantProfile**: 咨询师扩展信息 (资质、擅长领域、评分)
- **Conversation**: AI 咨询对话会话
- **Message**: 对话消息 (支持 text/image/audio 多模态)
- **PsychologicalProfile**: 心理画像 (人格特质、情绪趋势、风险等级)
- **HealingSession**: 疗愈室会话记录 (冥想/音乐/绘画等)
- **ExpertBooking**: 专家预约记录
- **ExpertMessage**: 专家咨询消息
- **TreatmentPlan**: 治疗规划 (阶段目标、进度追踪)
- **LearningRecord**: 学习记录 (推荐内容、完成进度)
- **Assessment**: 心理测评量表及结果

## 六大核心模块详细设计

### 模块一：AI 心理咨询

- 基于百度文心一言 API 的多轮对话系统
- 支持文本、图片（绘画/表情分析）多模态输入
- 内置心理咨询 Prompt 模板，遵循共情倾听 + CBT 认知行为疗法框架
- 对话上下文管理（滑动窗口 + 摘要压缩）
- 危机识别与预警机制（自伤/自杀关键词检测 -> 紧急干预流程）
- 咨询历史记录与回顾

### 模块二：患者心理画像

- 基于对话内容的情感分析（积极/消极/焦虑/抑郁等维度）
- 标准化心理量表评估（PHQ-9 抑郁、GAD-7 焦虑、SCL-90 等）
- 人格特质分析（基于对话模式推断）
- 情绪变化趋势可视化（折线图/雷达图）
- 综合心理画像报告生成（AI 辅助 + 咨询师审核）
- 风险等级自动评估（低/中/高/危机）

### 模块三：疗愈室

- AI 引导冥想（文本引导 + 背景音乐推荐）
- 情绪日记（文字/语音记录，AI 情感标注）
- 正念练习（呼吸引导、身体扫描等互动组件）
- 疗愈音乐/白噪音播放器
- 心情打卡（每日情绪记录，生成情绪日历）
- 疗愈内容个性化推荐（基于心理画像）

### 模块四：真人专家连线

- 咨询师列表（筛选：擅长领域、评分、价格、可用时间）
- 在线咨询预约系统（选择时间段、支付确认）
- 文字/语音消息实时通信（Socket.IO）
- 咨询会话管理（开始/结束/超时）
- 咨询评价与反馈
- 咨询师工作面板（患者列表、咨询记录、画像查看）

### 模块五：治疗规划

- AI 辅助生成个性化治疗方案（基于心理画像和咨询历史）
- 阶段性目标设定与追踪
- 治疗任务日历（每日/每周任务提醒）
- 进度可视化（完成度百分比、里程碑标记）
- 方案动态调整（AI 根据进展建议调整）
- 咨询师审核与修改治疗方案

### 模块六：持续学习

- 心理健康知识库（文章/视频/音频课程）
- AI 个性化内容推荐（基于心理画像和兴趣）
- 学习路径规划（按主题/难度分级）
- 学习进度追踪与成就系统
- 知识测验与反馈
- 学习笔记与心得分享

## 关键实现细节

### 百度文心一言 API 集成
- 统一封装 `AiService`，支持文本对话、情感分析、图像理解
- 使用流式响应 (SSE) 实现打字机效果
- Token 用量统计与限流控制
- 对话历史摘要压缩以节省 Token

### 实时通信架构
- Socket.IO 处理在线咨询消息
- Redis Adapter 支持水平扩展
- 消息持久化（先存数据库再推送）
- 离线消息队列与未读计数

### 安全与隐私
- 敏感数据加密存储（心理评估结果、咨询内容）
- API 请求限流与防刷
- RBAC 权限控制（患者只能看自己的数据）
- 咨询内容保密协议机制
