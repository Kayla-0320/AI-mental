# 青少年 AI 心理健康平台 —— 算法后端

> AIC 算法大赛参赛项目 · 后端算法模块

## 项目概述

本模块为青少年 AI 心理健康平台提供后端算法能力，采用 **四层架构**（感知 → 评估 → 干预 → 升级）配合公平性审计、隐私保护和联邦学习三大支撑体系，构建安全、可信、有效的智能心理健康服务。

## 各模块职责说明

### 1. perception（感知层）

**核心职责**：多模态情绪信号的采集与融合

从文本聊天、语音通话、面部表情、键盘/眨眼等行为模式四个通道实时采集情绪信号，通过多模态融合模块输出统一的情绪向量，为上层评估提供数据基础。

### 2. assessment（评估层）

**核心职责**：心理状态的量化评估与风险预测

基于感知层的情绪向量，结合标准化心理量表（PHQ-9、GAD-7 等）进行自动评分，利用时序模型追踪情绪趋势，输出风险等级和结构化评估报告。

### 3. intervention（干预层）

**核心职责**：分层智能干预方案生成与执行

根据评估结果匹配干预策略：轻度情绪波动 → CBT 对话 / 苏格拉底式提问；中度风险 → 个性化干预方案；高危信号 → 危机干预话术 + 安全计划。

### 4. escalation（升级层）

**核心职责**：危机信号的实时监测与专业转介

当感知层或评估层检测到高危信号时，立即触发升级流程：危机检测 → 自伤评估 → 紧急联系人通知 → 匹配推荐咨询师 → 预约协调。

### 5. audit（公平性审计）

**核心职责**：确保算法决策的公平性与透明度

持续监控模型在不同年龄、性别、地区等群体间的表现差异，计算公平性指标，提供 SHAP/LIME 可解释性报告，确保对青少年群体的算法决策公正可信。

### 6. privacy（隐私架构）

**核心职责**：全链路数据隐私保护

针对未成年人心理健康数据的特殊性，提供 PII 自动识别与脱敏、细粒度知情同意管理、端到端加密存储，确保符合《个人信息保护法》和《未成年人保护法》。

### 7. federated（联邦学习）

**核心职责**：隐私保护下的分布式模型协同训练

支持多所学校/机构在不共享原始数据的前提下协同训练情绪识别模型，通过 FedAvg/FedProx 聚合策略和差分隐私技术，在保护隐私的同时持续提升模型性能。

### 8. shared（共享数据类）

**核心职责**：全局通用组件的统一管理

提供跨模块复用的 Pydantic 数据模型、配置管理、工具函数和异常定义，避免各模块重复定义基础组件。
